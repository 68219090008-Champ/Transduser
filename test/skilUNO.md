# Arduino UNO R3 และขาใช้งาน

## Arduino UNO R3 คืออะไร

Arduino UNO R3 เป็นบอร์ดไมโครคอนโทรลเลอร์ที่นิยมใช้สำหรับเริ่มต้นเรียนรู้อิเล็กทรอนิกส์ การเขียนโปรแกรม และระบบสมองกลฝังตัว บอร์ดนี้ใช้ชิป ATmega328P เป็นตัวประมวลผลหลัก สามารถรับค่าจาก Sensor และสั่งงานอุปกรณ์ต่าง ๆ เช่น LED, Motor, Buzzer, Relay หรือ Display ได้

Arduino UNO R3 เหมาะสำหรับผู้เริ่มต้น เพราะใช้งานง่าย มีตัวอย่างเยอะ ต่อวงจรไม่ซับซ้อน และสามารถเขียนโปรแกรมผ่าน Arduino IDE หรือ PlatformIO ได้

## ข้อมูลพื้นฐานของบอร์ด

| รายการ | รายละเอียด |
| --- | --- |
| Microcontroller | ATmega328P |
| แรงดันใช้งาน | 5V |
| แรงดันไฟเข้าแนะนำ | 7-12V |
| Digital I/O Pins | 14 ขา |
| PWM Pins | 6 ขา |
| Analog Input Pins | 6 ขา |
| Flash Memory | 32 KB |
| SRAM | 2 KB |
| EEPROM | 1 KB |
| Clock Speed | 16 MHz |

## ส่วนประกอบสำคัญบนบอร์ด

- ช่อง USB ใช้สำหรับอัปโหลดโปรแกรมและจ่ายไฟให้บอร์ด
- ช่อง Power Jack ใช้ต่อ Adapter ภายนอก
- ปุ่ม Reset ใช้เริ่มการทำงานของโปรแกรมใหม่
- ชิป ATmega328P เป็นหน่วยประมวลผลหลัก
- ขา Digital ใช้รับหรือส่งสัญญาณดิจิทัล
- ขา Analog ใช้อ่านค่าสัญญาณแบบ Analog
- ขา Power ใช้จ่ายไฟให้ Sensor หรือ Module ต่าง ๆ
- LED บนบอร์ดที่ขา 13 ใช้ทดสอบโปรแกรมพื้นฐานได้

## ขา Digital I/O

ขา Digital ของ Arduino UNO R3 มีทั้งหมด 14 ขา คือ D0 ถึง D13 ใช้สำหรับรับหรือส่งค่าสัญญาณแบบดิจิทัล ซึ่งมีค่าเป็น HIGH หรือ LOW

ตัวอย่างการใช้งาน:

- อ่านค่าปุ่มกด
- เปิดปิด LED
- สั่งงาน Relay
- รับสัญญาณจาก Sensor แบบ Digital

### ขาที่ควรระวัง

- D0 และ D1 ใช้สำหรับ Serial Communication กับคอมพิวเตอร์
- ถ้าใช้อัปโหลดโปรแกรมหรือเปิด Serial Monitor ควรหลีกเลี่ยงการต่ออุปกรณ์ที่รบกวนขา D0 และ D1

## ขา PWM

ขา PWM เป็นขา Digital ที่สามารถจำลองสัญญาณ Analog ได้ โดยใช้คำสั่ง `analogWrite()` เหมาะสำหรับควบคุมความสว่างหรือความเร็ว

ขา PWM บน Arduino UNO R3 ได้แก่:

- D3
- D5
- D6
- D9
- D10
- D11

ตัวอย่างการใช้งาน:

- ปรับความสว่าง LED
- ควบคุมความเร็วมอเตอร์
- ควบคุม Servo หรือ Module บางชนิด

## ขา Analog Input

ขา Analog Input มีทั้งหมด 6 ขา คือ A0 ถึง A5 ใช้สำหรับอ่านค่าสัญญาณ Analog จาก Sensor โดยค่าที่อ่านได้มีช่วง 0 ถึง 1023

ตัวอย่าง Sensor ที่ใช้กับขา Analog:

- LDR Sensor ตรวจจับแสง
- Potentiometer ปรับค่าด้วยมือหมุน
- Soil Moisture Sensor ตรวจวัดความชื้นในดิน
- Sound Sensor ตรวจจับเสียง

ตัวอย่างคำสั่งอ่านค่า Analog:

```cpp
int sensorValue = analogRead(A0);
```

## ขา Power

ขา Power ใช้สำหรับจ่ายไฟหรืออ้างอิงแรงดันให้กับวงจรภายนอก

| ขา | หน้าที่ |
| --- | --- |
| VIN | รับไฟจากแหล่งจ่ายภายนอก |
| 5V | จ่ายไฟ 5V ให้ Module หรือ Sensor |
| 3.3V | จ่ายไฟ 3.3V สำหรับอุปกรณ์ที่ใช้แรงดันต่ำ |
| GND | กราวด์ของวงจร |
| RESET | รีเซ็ตการทำงานของบอร์ด |
| IOREF | แสดงแรงดันอ้างอิงของบอร์ด |

## ขาสื่อสาร Serial, I2C และ SPI

Arduino UNO R3 รองรับการสื่อสารหลายรูปแบบ เพื่อเชื่อมต่อกับ Sensor หรือ Module ต่าง ๆ

### Serial Communication

ใช้สำหรับสื่อสารกับคอมพิวเตอร์หรืออุปกรณ์ Serial อื่น

- D0 = RX
- D1 = TX

### I2C Communication

ใช้สำหรับสื่อสารกับอุปกรณ์หลายตัวโดยใช้สายเพียง 2 เส้น

- A4 = SDA
- A5 = SCL

ตัวอย่างอุปกรณ์ I2C:

- LCD I2C
- RTC Module
- Sensor แบบ I2C

### SPI Communication

ใช้สำหรับสื่อสารความเร็วสูงกับ Module บางชนิด

- D10 = SS
- D11 = MOSI
- D12 = MISO
- D13 = SCK

ตัวอย่างอุปกรณ์ SPI:

- SD Card Module
- RFID Module
- Display บางรุ่น

## ตัวอย่างการใช้งานขา Arduino UNO R3

| งานที่ต้องการ | ขาที่แนะนำ |
| --- | --- |
| ต่อ LED | D2-D13 |
| ต่อปุ่มกด | D2-D13 |
| อ่านค่า Sensor Analog | A0-A5 |
| ควบคุมความสว่าง LED | D3, D5, D6, D9, D10, D11 |
| ใช้ Serial Monitor | D0, D1 |
| ใช้จอ LCD I2C | A4, A5 |
| ใช้ SD Card Module | D10-D13 |

## ข้อควรระวังในการใช้งาน

- ห้ามต่อไฟเกินแรงดันที่บอร์ดหรือขารับได้
- ขา I/O ของ Arduino UNO ใช้สัญญาณ 5V
- ควรต่อ GND ร่วมกันทุกครั้งเมื่อใช้อุปกรณ์ภายนอก
- หลีกเลี่ยงการดึงกระแสจากขา I/O มากเกินไป
- ตรวจสอบ Datasheet ของ Sensor หรือ Module ก่อนต่อวงจร
- ระวังการต่อ VCC และ GND ผิดขั้ว เพราะอาจทำให้อุปกรณ์เสียหาย

## สรุป

Arduino UNO R3 เป็นบอร์ดที่เหมาะสำหรับเริ่มต้นเรียนรู้การเขียนโปรแกรมควบคุมอุปกรณ์อิเล็กทรอนิกส์ ขาใช้งานหลักแบ่งเป็นขา Digital, PWM, Analog, Power และขาสื่อสาร เช่น Serial, I2C และ SPI หากเข้าใจหน้าที่ของแต่ละขา จะสามารถต่อ Sensor และ Module ต่าง ๆ ได้ถูกต้องและปลอดภัยมากขึ้น
