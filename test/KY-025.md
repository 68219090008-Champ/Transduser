# การออกแบบวงจรและโปรแกรม: ระบบแจ้งเตือนการเปิดประตูเครื่องจักรด้วย KY-025 และ Arduino UNO

## 1. Wiring Diagram

### อุปกรณ์
- KY-025 Magnetic Reed Switch Sensor
- Arduino UNO
- LCD I2C 16x2
- Buzzer

---

## 2. การต่อวงจร (Connection Table)

### KY-025 → Arduino UNO

| KY-025 | Arduino UNO |
|---|---|
| VCC | 5V |
| GND | GND |
| DO | D7 |

### LCD I2C → Arduino UNO

| LCD I2C | Arduino UNO |
|---|---|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

### Buzzer → Arduino UNO

| Buzzer | Arduino UNO |
|---|---|
| ขา + | D5 |
| ขา - | GND |

---

## 3. สัญลักษณ์สีสายไฟ (Wire Color Guide)

| สีสายไฟ | หน้าที่ |
|---|---|
| 🔴 สีแดง | สายไฟ 5V |
| ⚫ สีดำ | สาย GND |
| 🔵 สีน้ำเงิน | สัญญาณจาก KY-025 (DO → D7) |
| 🟣 สีม่วง | สัญญาณควบคุม Buzzer (D8) |
| 🟢 สีเขียว | I2C SDA (A4) |
| 🟡 สีเหลือง | I2C SCL (A5) |

---

## 4. คำอธิบายการทำงาน

### เมื่อประตูปิด
*(แม่เหล็กอยู่ใกล้ KY-025)*

- DO = LOW
- จอ LCD แสดงข้อความ **“ปิดอยู่ (ปลอดภัย)”**
- Buzzer ไม่ทำงาน

### เมื่อประตูเปิด
*(แม่เหล็กห่างจาก KY-025)*

- DO = HIGH
- จอ LCD แสดงข้อความ **“เปิดอยู่ (อันตราย)”**
- Buzzer ส่งเสียงเตือน

---

## 5. หมายเหตุ

> ปรับตำแหน่งแม่เหล็กและเซ็นเซอร์ให้เหมาะสม เพื่อให้ตรวจจับได้แม่นยำ

---

## 6. สรุปการทำงานของระบบ

ระบบใช้ **KY-025** ตรวจจับสถานะการเปิด–ปิดประตูเครื่องจักร โดยส่งสัญญาณดิจิทัลไปยัง **Arduino UNO** ผ่านขา D7 จากนั้น Arduino UNO จะประมวลผลสถานะและแสดงผลผ่าน **LCD I2C** พร้อมสั่งงาน **Buzzer** เพื่อแจ้งเตือนเมื่อประตูเครื่องจักรถูกเปิด
