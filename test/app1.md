# ออกแบบการใช้ Sensor KY-025 กับเครื่องรดน้ำต้นไม้อัตโนมัติ

## แนวคิดของโครงงาน

โครงงานเดิมคือเครื่องรดน้ำต้นไม้อัตโนมัติ ซึ่งใช้ Arduino UNO ควบคุมการเปิด/ปิดปั๊มน้ำตามเงื่อนไขที่กำหนด เช่น ความชื้นในดินหรือเวลาที่ต้องการรดน้ำ

ในการออกแบบนี้จะนำ Sensor KY-025 Magnetic Reed Switch Sensor มาเกี่ยวข้องกับโครงงาน โดยใช้เป็น Sensor ตรวจสอบระดับน้ำในถังเก็บน้ำร่วมกับลูกลอยแม่เหล็ก เพื่อป้องกันไม่ให้ปั๊มน้ำทำงานในขณะที่น้ำในถังหมดหรือมีระดับต่ำเกินไป

แนวคิดคือ

- ถ้าน้ำในถังมีเพียงพอ ลูกลอยแม่เหล็กจะอยู่ใกล้ KY-025 ระบบอนุญาตให้ปั๊มน้ำทำงาน
- ถ้าน้ำในถังต่ำ ลูกลอยแม่เหล็กจะเลื่อนออกห่าง KY-025 ระบบจะหยุดปั๊มน้ำและแจ้งเตือนผ่าน Serial Monitor

วิธีนี้ทำให้ KY-025 ไม่ได้ใช้ตรวจดินโดยตรง แต่ใช้ตรวจความพร้อมของแหล่งน้ำ ซึ่งเป็นส่วนสำคัญของเครื่องรดน้ำต้นไม้อัตโนมัติ

## วัตถุประสงค์

- ประยุกต์ใช้ KY-025 กับโครงงานเครื่องรดน้ำต้นไม้อัตโนมัติ
- ตรวจสอบว่าน้ำในถังมีเพียงพอก่อนเปิดปั๊มน้ำ
- ป้องกันปั๊มน้ำเสียหายจากการทำงานตอนน้ำหมด
- แสดงสถานะระดับน้ำและสถานะปั๊มน้ำผ่าน Serial Monitor
- เป็นแนวทางต่อยอดระบบรดน้ำต้นไม้ให้ปลอดภัยและใช้งานจริงได้มากขึ้น

## บทบาทของ KY-025 ในระบบ

KY-025 เป็น Sensor ตรวจจับสนามแม่เหล็กแบบ Reed Switch เมื่อนำแม่เหล็กเข้าใกล้ Sensor ค่าที่ขา Digital Output หรือ `D0` จะเปลี่ยนสถานะ

ในโครงงานนี้ให้นำแม่เหล็กติดกับลูกลอยในถังน้ำ เมื่อน้ำอยู่ในระดับที่กำหนด ลูกลอยจะพาแม่เหล็กมาอยู่ใกล้ Sensor ทำให้ Arduino รู้ว่าน้ำยังมีเพียงพอ แต่เมื่อน้ำลดต่ำลง ลูกลอยจะเคลื่อนออกจาก Sensor ทำให้ Arduino รู้ว่าน้ำต่ำเกินไปและควรหยุดปั๊ม

## ภาพรวมการทำงานของระบบ

1. Soil Moisture Sensor ตรวจวัดความชื้นในดิน
2. KY-025 ตรวจสอบว่าน้ำในถังมีเพียงพอหรือไม่
3. Arduino UNO อ่านค่าจาก Sensor ทั้งสองตัว
4. ถ้าดินแห้งและน้ำในถังเพียงพอ ระบบจะเปิดปั๊มน้ำ
5. ถ้าดินชื้น หรือระดับน้ำต่ำ ระบบจะปิดปั๊มน้ำ
6. Serial Monitor แสดงค่าความชื้น สถานะระดับน้ำ และสถานะปั๊มน้ำ

## การติดตั้ง KY-025 กับถังน้ำ

ติดตั้ง KY-025 ไว้ด้านนอกถังน้ำบริเวณระดับน้ำขั้นต่ำที่ต้องการให้ระบบยังทำงานได้ จากนั้นติดแม่เหล็กไว้กับลูกลอยภายในถัง

เมื่อระดับน้ำสูงพอ ลูกลอยจะอยู่ใกล้ตำแหน่ง Sensor ทำให้ KY-025 ตรวจพบแม่เหล็ก แต่เมื่อน้ำลดต่ำกว่าระดับที่กำหนด ลูกลอยจะเลื่อนออกจาก Sensor ทำให้สถานะเปลี่ยนไป

ข้อดีของวิธีนี้คือ Sensor ไม่ต้องสัมผัสน้ำโดยตรง จึงช่วยลดปัญหาสนิม การกัดกร่อน และความเสียหายจากความชื้น

## เงื่อนไขการควบคุม

ตัวอย่างนี้กำหนดให้ Soil Moisture Sensor อ่านค่า Analog สูงเมื่อดินแห้ง และกำหนดให้ KY-025 อ่านค่า `HIGH` เมื่อมีน้ำเพียงพอ

| เงื่อนไข | การทำงานของปั๊มน้ำ |
| --- | --- |
| ดินแห้ง และน้ำในถังเพียงพอ | เปิดปั๊มน้ำ |
| ดินแห้ง แต่น้ำในถังต่ำ | ปิดปั๊มน้ำ และแจ้งเตือนน้ำหมด |
| ดินชื้นเพียงพอ | ปิดปั๊มน้ำ |

หมายเหตุ: โมดูล KY-025 บางรุ่นอาจให้ค่า Logic กลับกัน ถ้าทดสอบแล้วพบว่าค่า `LOW` หมายถึงตรวจพบแม่เหล็ก ให้แก้เงื่อนไขในโปรแกรมให้ตรงกับ Sensor จริง

## ตัวอย่างโค้ด Arduino

```cpp
#include <Arduino.h>

const int moisturePin = A0;
const int waterLevelPin = 3;
const int relayPin = 7;

const int dryThreshold = 600;
const unsigned long readInterval = 1000;

void setup() {
  pinMode(waterLevelPin, INPUT);
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, LOW);

  Serial.begin(9600);
  Serial.println("Automatic Plant Watering with KY-025");
  Serial.println("-------------------------------------");
}

void loop() {
  int moistureValue = analogRead(moisturePin);
  int waterLevelState = digitalRead(waterLevelPin);

  bool soilIsDry = moistureValue > dryThreshold;
  bool waterIsEnough = waterLevelState == HIGH;

  Serial.print("Soil moisture = ");
  Serial.print(moistureValue);
  Serial.print(" | Water = ");

  if (waterIsEnough) {
    Serial.print("ENOUGH");
  } else {
    Serial.print("LOW");
  }

  Serial.print(" | Pump = ");

  if (soilIsDry && waterIsEnough) {
    digitalWrite(relayPin, HIGH);
    Serial.println("ON");
  } else {
    digitalWrite(relayPin, LOW);

    if (!waterIsEnough) {
      Serial.println("OFF - water tank low");
    } else {
      Serial.println("OFF - soil moisture enough");
    }
  }

  delay(readInterval);
}
```

หมายเหตุ: Relay บางรุ่นเป็นแบบ Active LOW คือสั่งงานด้วย `LOW` แทน `HIGH` หากปั๊มน้ำทำงานกลับด้าน ให้สลับคำสั่ง `HIGH` และ `LOW` ในส่วนควบคุม Relay

## ผลลัพธ์ที่คาดว่าจะได้ใน Serial Monitor

```text
Automatic Plant Watering with KY-025
-------------------------------------

Soil moisture = 680 | Water = ENOUGH | Pump = ON
Soil moisture = 710 | Water = LOW | Pump = OFF - water tank low

```

จากผลลัพธ์จะเห็นว่าแม้ดินจะแห้ง แต่ถ้า KY-025 ตรวจพบว่าน้ำในถังต่ำ ระบบจะไม่เปิดปั๊มน้ำ เพื่อป้องกันปั๊มทำงานโดยไม่มีน้ำ

## ข้อควรระวัง

- KY-025 ตรวจจับแม่เหล็กในระยะใกล้ จึงต้องจัดตำแหน่ง Sensor กับลูกลอยให้เหมาะสม
- ควรทดสอบก่อนว่า Sensor ให้ค่า `HIGH` หรือ `LOW` เมื่อพบแม่เหล็ก
- ระวังไม่ให้น้ำกระเด็นโดน Arduino, Relay และสายไฟ
- ปั๊มน้ำไม่ควรรับไฟจากขา Arduino โดยตรง ต้องใช้ Relay หรือ Driver Module
- ถ้าใช้แหล่งจ่ายไฟแยก ต้องต่อ GND ร่วมกันให้ถูกต้อง
- ควรติดตั้ง Sensor ด้านนอกถังหรือมีฉนวนป้องกันความชื้น

## สรุป

การนำ KY-025 มาใช้กับเครื่องรดน้ำต้นไม้อัตโนมัติสามารถทำได้โดยให้ Sensor ทำหน้าที่ตรวจสอบระดับน้ำในถังผ่านลูกลอยแม่เหล็ก ระบบจะเปิดปั๊มน้ำเฉพาะเมื่อดินแห้งและมีน้ำเพียงพอเท่านั้น ทำให้โครงงานเดิมมีความปลอดภัยมากขึ้น ลดความเสี่ยงที่ปั๊มน้ำจะเสียหาย และสามารถต่อยอดเป็นระบบรดน้ำต้นไม้อัตโนมัติที่ใช้งานจริงได้ดียิ่งขึ้น
