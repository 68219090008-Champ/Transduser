# Transduser

## โครงงานวัดอุณหภูมิและความชื้นด้วย DHT11

โครงงานนี้ออกแบบเพื่อใช้ Arduino UNO R3 อ่านค่าอุณหภูมิและความชื้นจากเซ็นเซอร์ DHT11 แล้วแสดงผลทั้งบนจอ LCD I2C 16x2 และใน Serial Monitor

## วัตถุประสงค์

- อ่านค่าอุณหภูมิและความชื้นจาก DHT11
- แสดงผลบนจอ LCD I2C แบบ 16x2
- แสดงผลค่าเดียวกันใน Serial Monitor เพื่อช่วยตรวจสอบข้อมูล
- เหมาะสำหรับงานเรียนรู้และโครงงานเชิงทดลองเกี่ยวกับเซ็นเซอร์และ I2C

## อุปกรณ์ที่ใช้

- Arduino UNO R3
- เซ็นเซอร์ DHT11
- จอ LCD I2C 16x2
- สาย jumper
- แหล่งจ่ายไฟ 5V

## การเชื่อมต่ออุปกรณ์

### DHT11

- VCC -> 5V
- GND -> GND
- DATA -> Digital Pin 4 (D4)

### LCD I2C

- VCC -> 5V
- GND -> GND
- SDA -> A4
- SCL -> A5

### ข้อมูลเพิ่มเติม

- Address ของ LCD -> 0x27

## โครงสร้างโปรเจกต์

- src/main.cpp : โค้ดหลักสำหรับอ่านค่าเซ็นเซอร์และแสดงผล
- platformio.ini : การกำหนดบอร์ดและไลบรารีที่ใช้
- test/meet.md : เอกสารอ้างอิงเกี่ยวกับการเชื่อมต่อฮาร์ดแวร์

## ไลบรารีที่ใช้

- DHT sensor library
- Adafruit Unified Sensor
- LiquidCrystal_I2C

## วิธีรันโปรเจกต์

1. เปิดโฟลเดอร์โปรเจกต์ใน PlatformIO IDE
2. ตรวจสอบให้แน่ใจว่าได้ติดตั้งไลบรารีที่จำเป็นแล้ว
3. คอมไพล์โปรเจกต์ด้วยคำสั่ง:
   - pio run
4. อัปโหลดลง Arduino UNO ด้วยคำสั่ง:
   - pio run --target upload
5. เปิด Serial Monitor เพื่อดูค่าที่อ่านได้

## ตัวอย่างผลลัพธ์

เมื่อโปรแกรมทำงานจะแสดงผลดังนี้

- บน LCD I2C:
  - Temp: xx.x C
  - Hum: xx.x %
- บน Serial Monitor:
  - Temperature: xx.x C  Humidity: xx.x %

## หมายเหตุ

หากจอ LCD ไม่แสดงผล ให้ตรวจสอบว่า:

- การต่อ SDA/SCL ถูกต้อง
- Address ของ LCD เป็น 0x27
- ไดรเวอร์และไลบรารีถูกติดตั้งแล้ว

## สรุป

โปรเจกต์นี้เป็นตัวอย่างพื้นฐานของการใช้ DHT11 ร่วมกับ LCD I2C ใน Arduino UNO เพื่อแสดงผลอุณหภูมิและความชื้นแบบเรียลไทม์
