# สรุปความรู้ Sensor เบื้องต้น

## Sensor คืออะไร

Sensor หรือ เซนเซอร์ คืออุปกรณ์ที่ใช้ตรวจจับค่าทางกายภาพจากสิ่งแวดล้อม แล้วแปลงค่านั้นให้อยู่ในรูปแบบสัญญาณที่ไมโครคอนโทรลเลอร์หรือคอมพิวเตอร์สามารถนำไปประมวลผลได้ เช่น แรงดันไฟฟ้า กระแสไฟฟ้า หรือข้อมูลดิจิทัล

ตัวอย่างสิ่งที่ Sensor ตรวจจับได้ เช่น

- อุณหภูมิ
- ความชื้น
- แสง
- ระยะทาง
- การเคลื่อนไหว
- แรงกด
- เสียง
- ก๊าซหรือควัน

## หลักการทำงานพื้นฐาน

การทำงานของ Sensor โดยทั่วไปมีขั้นตอนดังนี้

1. ตรวจจับสิ่งแวดล้อมหรือปริมาณทางกายภาพ
2. แปลงค่าที่ตรวจจับได้เป็นสัญญาณไฟฟ้า
3. ส่งสัญญาณไปยังบอร์ดควบคุม เช่น Arduino, ESP32 หรือไมโครคอนโทรลเลอร์อื่น
4. โปรแกรมอ่านค่าและนำไปประมวลผล
5. แสดงผลหรือสั่งงานอุปกรณ์อื่น เช่น LED, Motor, Buzzer หรือ Relay

## ประเภทของ Sensor

### 1. Analog Sensor

Analog Sensor คือ Sensor ที่ส่งค่าต่อเนื่องออกมาเป็นแรงดันไฟฟ้า เช่น 0-5V หรือ 0-3.3V ค่าที่ได้จะเปลี่ยนไปตามสิ่งที่ตรวจจับ

ตัวอย่าง:

- LDR Sensor ตรวจจับแสง
- Soil Moisture Sensor ตรวจจับความชื้นในดิน
- Potentiometer ตรวจจับตำแหน่งการหมุน

### 2. Digital Sensor

Digital Sensor คือ Sensor ที่ส่งค่าออกมาเป็นสัญญาณดิจิทัล เช่น 0 หรือ 1 หรือส่งข้อมูลผ่านโปรโตคอลสื่อสาร

ตัวอย่าง:

- PIR Sensor ตรวจจับการเคลื่อนไหว
- DHT11/DHT22 ตรวจวัดอุณหภูมิและความชื้น
- Ultrasonic Sensor ตรวจวัดระยะทาง

## ตัวอย่าง Sensor ที่พบบ่อย

| Sensor | หน้าที่ |
| --- | --- |
| LDR | ตรวจจับความเข้มของแสง |
| DHT11/DHT22 | วัดอุณหภูมิและความชื้น |
| Ultrasonic HC-SR04 | วัดระยะทางด้วยคลื่นเสียง |
| PIR | ตรวจจับการเคลื่อนไหวของคนหรือสัตว์ |
| MQ Series | ตรวจจับก๊าซหรือควัน |
| Soil Moisture | ตรวจวัดความชื้นในดิน |

## การอ่านค่า Sensor ด้วยไมโครคอนโทรลเลอร์

เมื่อต่อ Sensor เข้ากับบอร์ดควบคุม ต้องเลือกขาให้เหมาะสมกับชนิดของสัญญาณ

- Sensor แบบ Analog ควรต่อกับขา Analog Input
- Sensor แบบ Digital ควรต่อกับขา Digital Input
- Sensor ที่ใช้ I2C มักใช้ขา SDA และ SCL
- Sensor ที่ใช้ SPI มักใช้ขา MOSI, MISO, SCK และ CS

## ข้อควรระวังในการใช้งาน

- ตรวจสอบแรงดันไฟเลี้ยงของ Sensor ว่าใช้ 3.3V หรือ 5V
- ต่อขา VCC, GND และ Signal ให้ถูกต้อง
- อ่าน Datasheet หรือคู่มือก่อนใช้งาน
- ระวังการต่อไฟผิดขั้ว เพราะอาจทำให้ Sensor เสียหาย
- ควรทดสอบค่า Sensor ด้วย Serial Monitor ก่อนนำไปใช้งานจริง
- Sensor บางชนิดต้อง Calibrate หรือปรับเทียบค่าก่อนใช้งาน

## Sensor DHT11

DHT11 เป็น Sensor สำหรับวัดอุณหภูมิและความชื้นในอากาศ นิยมใช้กับงาน Arduino, ESP32 และโครงงาน IoT เบื้องต้น เพราะต่อวงจรไม่ซับซ้อนและอ่านค่าได้เป็นข้อมูลดิจิทัล
DHT11 เป็น Sensor สำหรับตรวจวัดอุณหภูมิและความชื้นสัมพัทธ์ในอากาศ นิยมใช้กับ Arduino, ESP32 และโครงงาน IoT เบื้องต้น เพราะราคาถูก ต่อวงจรไม่ซับซ้อน และส่งข้อมูลออกมาเป็นสัญญาณดิจิทัล

### คุณสมบัติพื้นฐาน

- วัดอุณหภูมิได้ประมาณ 0-50 องศาเซลเซียส
- วัดความชื้นสัมพัทธ์ได้ประมาณ 20-90% RH
- ใช้ไฟเลี้ยงได้ประมาณ 3.3V-5V
- ส่งข้อมูลผ่านขา DATA แบบ Digital
- เหมาะสำหรับการเรียนรู้และโครงงานทดลองทั่วไป
- ความแม่นยำไม่สูงมาก หากต้องการความละเอียดมากขึ้นอาจใช้ DHT22 แทน
| รายการ | รายละเอียด |
| --- | --- |
| ค่าที่วัดได้ | อุณหภูมิ และความชื้นสัมพัทธ์ |
| ช่วงวัดอุณหภูมิ | ประมาณ 0-50 องศาเซลเซียส |
| ช่วงวัดความชื้น | ประมาณ 20-90% RH |
| แรงดันไฟเลี้ยง | ประมาณ 3.3V-5V |
| สัญญาณข้อมูล | Digital ผ่านขา DATA |
| ความถี่ในการอ่านค่า | ควรอ่านทุก 1-2 วินาที |

DHT11 เหมาะสำหรับงานเรียนรู้และโครงงานทดลองทั่วไป เช่น เครื่องวัดอุณหภูมิในห้อง หรือระบบติดตามความชื้นแบบง่าย หากต้องการความแม่นยำและความละเอียดสูงกว่า ควรพิจารณาใช้ DHT22 หรือ Sensor รุ่นอื่น

### ขาของ DHT11

โมดูล DHT11 ที่ใช้ในการเรียนมักมี 3 ขา แต่ตัว Sensor แบบเปลือยบางรุ่นอาจมี 4 ขา

| ขา | หน้าที่ |
| --- | --- |
| VCC | ต่อไฟเลี้ยง 3.3V หรือ 5V |
| DATA / OUT | ส่งข้อมูลอุณหภูมิและความชื้นไปยังบอร์ดควบคุม |
| GND | ต่อกราวด์ |
| NC | ไม่มีการใช้งาน พบใน DHT11 บางรุ่น |
| NC | ไม่มีการใช้งาน พบในรุ่น 4 ขา |

### หลักการทำงาน

ภายใน DHT11 มีส่วนตรวจวัดความชื้นและอุณหภูมิ เมื่อ Sensor ตรวจจับค่าได้แล้ว วงจรภายในจะแปลงค่าเป็นสัญญาณดิจิทัล จากนั้นส่งข้อมูลผ่านขา DATA ไปยังไมโครคอนโทรลเลอร์ โปรแกรมจึงสามารถนำค่าที่อ่านได้ไปแสดงผลหรือใช้ควบคุมอุปกรณ์อื่น
ภายใน DHT11 มีส่วนตรวจวัดความชื้นและส่วนตรวจวัดอุณหภูมิ เมื่อ Sensor ตรวจจับค่าได้แล้ว วงจรภายในจะแปลงค่าเป็นข้อมูลดิจิทัล จากนั้นส่งข้อมูลผ่านขา DATA ไปยังไมโครคอนโทรลเลอร์ โปรแกรมจึงสามารถนำค่าที่อ่านได้ไปแสดงผลหรือใช้ควบคุมอุปกรณ์อื่น เช่น LED, พัดลม, Buzzer หรือ Relay

### ตัวอย่างโค้ด Arduino เบื้องต้น

ตัวอย่างนี้ใช้ไลบรารี DHT sensor library เพื่ออ่านค่าอุณหภูมิและความชื้น แล้วแสดงผลผ่าน Serial Monitor

```cpp
#include <Arduino.h>
#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("อ่านค่า DHT11 ไม่สำเร็จ");
    return;
  }

  Serial.print("Humidity: ");
  Serial.print(humidity);
  Serial.print("%  Temperature: ");
  Serial.print(temperature);
  Serial.println(" C");

  delay(2000);
}
```

### ตัวอย่างการนำไปใช้งาน

- เครื่องวัดอุณหภูมิและความชื้นในห้อง
- ระบบ Smart Farm หรือโรงเรือนปลูกพืช
- โครงงาน IoT ที่ส่งค่าอุณหภูมิและความชื้นไปแสดงผลบนแอปหรือเว็บ
